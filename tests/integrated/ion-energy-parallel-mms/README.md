# Parallel-current ion-energy MMS

The symbolic `parallel_current` variant is generated by
`../ion-energy-mms/mms.py --variant parallel_current --check`. Its continuum
reference and forcing share the existing two-ion Reynolds MMS machinery.
Electron momentum is independently manufactured and evolved; `zero_current`
is removed. With `a=pi X/10`, `b=2 pi Y/10`, `theta=2 pi Z/10-t/5`, the added
current is `0.03 cos(2a) sin(b-t/5) cos(theta)`. Its analytic auxiliary inverse
is `-0.03 cos(2a) cos(b-t/5) cos(theta)/(4 c pi/10)`, with `c=2`.
The added cosine satisfies Neumann X AC conditions and zero DC wall values.
Y and Z are periodic. Production sheath conditions belong to the separate
`ion-energy-sheath` regression.

Run `runtest --exe /path/to/hermes-3 --output-root /path/to/evidence` with the
configured Python environment. It advances to normalised time 0.02 at three
spatial levels (8, 16, 32 X/Z cells and twice that number of Y cells), repeats
16 cells with tighter temporal settings, and compares the 8-cell run with a
different serial/MPI Y decomposition. The fixed 32 auxiliary corrections
separate inverse error from spatial truncation; no numerical method is changed.

The runner checks each completed refinement pair before launching the next
grid. A failed physics, accuracy or temporal block exits through the result
writer and stops subsequent validation. Reusing completed 8/16-cell outputs
with `--reuse-root` therefore reports their accuracy failures before any new
solver run. Explicitly authorised diagnostic continuations use separate
scripts recorded in the review report; the default runner has no bypass.

`criteria.json` requires L2 orders at least 1.7 for 8-to-16 and 1.8 for
16-to-32, and Linfinity orders at least 1.5. It measures all evolved fields,
recovered ion/electron temperatures and pressures, phi, psi and chi. Original
field-error caps are retained; electron momentum, temperature and chi have
separate declared caps. Temporal differences must be below 5% of the measured
spatial error (with an absolute floor of `1e-11`); auxiliary residual,
continuity, recovery and MPI differences must be below `1e-10`.

The forcing is injected by BOUT's MMS mechanism once; electron pressure and
total-ion-energy physical source diagnostics must remain zero to `1e-12`.
Nonzero Reynolds, parallel-current and polarisation terms are checked
independently. No existing MMS accuracy deferral applies to this test.
